Basic Alerts
Dismiss + icon + long text
notifications

Bilgilendirme

Bu işlem başarıyla tamamlandı. Gerekli kayıtlar sisteme işlendi.
check_circle

Başarılı

Kaydınız başarıyla oluşturuldu.
warning

Uyarı

Bu alan eksik görünüyor. Lütfen kaydetmeden önce tüm zorunlu alanları kontrol edin. Uzun metin test: satır sonları, taşma, okunurluk ve gap davranışı.
error

Hata

İşlem sırasında beklenmeyen bir hata oluştu. Lütfen tekrar deneyin.
States & Accessibility
focus-visible + disabled
info

Focus Test

Klavyeyle (Tab) kapatma ikonuna gel: focus ring görünmeli. Mouse ile tıklayınca ring çıkmamalı.
lock

Disabled Close

Bu alert’te close butonu disabled. Disabled state: opacity + cursor + pointer-events.
Not: Theme switcher data-bs-theme değiştirir. Density toggle data-bb-density="compact" ekler/çıkarır.
Nasıl kullanılır

Temel uyarı

Renk bb-alert-primary|success|warning|danger ile seçilir. Kapatma düğmesi Bootstrap data-bs-dismiss="alert" ile çalışır.

HTML
<div class="alert bb-alert bb-alert-success mb-4" role="alert">
    <div class="bb-alert-icon" aria-hidden="true">
        <span class="material-symbols-outlined">check_circle</span>
    </div>

    <div class="bb-alert-body">
        <h4 class="bb-alert-title">Başarılı</h4>
        <div class="bb-alert-text">
            Kaydınız başarıyla oluşturuldu.
        </div>
    </div>
</div>
