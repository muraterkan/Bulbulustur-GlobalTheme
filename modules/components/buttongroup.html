How do I use it?

Basic Group

Place buttons inside a btn-group bb-btn-group; use bb-btn-group-soft, bb-btn-group-pill, or bb-btn-group-compact for different visual styles.

HTML 
<div class="btn-group bb-btn-group" role="group" aria-label="Solid group">
    <button type="button" class="btn btn-sm btn-primary active" aria-pressed="true">
        Overview
    </button>
    <button type="button" class="btn btn-sm btn-primary">
        Products
    </button>
    <!-- ... aynı yapıda diğer öğeler ... -->
</div>

Vertical Group

btn-group-vertical buttons are arranged vertically.

HTML 
<div class="btn-group-vertical bb-btn-group bb-btn-group-soft" role="group" aria-label="Vertical group">
    <button type="button" class="btn btn-sm bb-btn-outline-primary">
        Top
    </button>
    <button type="button" class="btn btn-sm bb-btn-outline-primary active" aria-pressed="true">
        Middle
    </button>
    <!-- ... aynı yapıda diğer öğeler ... -->
</div>
