How do I use it?

Open (Soft) Badge

bb-badge + color class. For a soft appearance, use bb-badge-light-*, and for a filled appearance, use bb-badge-primary|success|danger.

HTML 
<span class="badge bb-badge bb-badge-light-success">Light Success</span>

Size and Shape

bb-badge-sm, bb-badge-lg, bb-badge-pill, bb-badge-circle ile boyut ve şekil değişir.

HTML 
<span class="badge bb-badge bb-badge-pill bb-badge-light-primary">Pill Light</span>
