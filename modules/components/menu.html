How do I use it?

Dikey menü

Kök bb-menu + data-bb-menu="true". Öğe: bb-menu-item > bb-menu-link (ikon, başlık). Aktif öğeye active verin. Alt menü açılır paneli bb-menu-sub ile yazılır.

HTML 
<div class="bb-menu bb-menu-column bb-menu-hover-bg bb-menu-active-bg bb-menu-here-bg bb-menu-sub-indention w-100"
     data-bb-menu="true">

    <div class="bb-menu-section">MENU</div>

    <!-- Dashboards (simple) -->
    <div class="bb-menu-item active here">
        <a href="#" class="bb-menu-link active">
            <span class="bb-menu-icon">
                <span class="material-symbols-outlined">dashboard</span>
            </span>
            <span class="bb-menu-title">Dashboards</span>
        </a>
    </div>

    <div class="bb-menu-separator"></div>

    <div class="bb-menu-section">PAGES</div>

    <!-- User Profile (accordion) -->
    <div class="bb-menu-item"
         data-bb-menu-trigger="click"
         aria-expanded="true">
        <a href="#" class="bb-menu-link">
            <span class="bb-menu-icon">
                <span class="material-symbols-outlined">person</span>
            </span>
            <span class="bb-menu-title">User Profile</span>
            <span class="bb-menu-arrow"></span>
        </a>

        <div class="bb-menu-sub bb-menu-sub-accordion">
            <div class="bb-menu-sub-content">

<!-- ... -->

Header menüleri sayfa içeriğinin üstünde kalır (--bb-z-header: 1030); sticky içerik 1020 altında tutulmalıdır.
