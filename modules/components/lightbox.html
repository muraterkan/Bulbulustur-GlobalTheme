Lightbox

Vendor-free galeri. .bb-lightbox-trigger + data-bb-lightbox-group. (ESC / ← → / dblclick zoom / Z)
Gallery Demo
Tıklayınca açılır. Backdrop’a tıklayınca kapanır.
Group: gallery
Öneri: Trigger elemanına href veriyoruz; JS data-bb-lightbox-src varsa onu, yoksa href/src’yi kullanır.
Usage
Markup + script include.
HTML
<img
  class="bb-lightbox-trigger"
  data-bb-lightbox-group="gallery"
  data-bb-lightbox-src="https://..."
  src="https://..."
  alt=""
/>
JS
<script src="../../assets/js/core/bb-lightbox.js"></script>
How do I use it?

Resim büyütme

Tetikleyiciye bb-lightbox-trigger ve data-bb-lightbox-src verin. Aynı data-bb-lightbox-group değerine sahip görseller galeri olur.

HTML 
<img src="https://picsum.photos/id/1015/800/600"
class="img-fluid rounded bb-lightbox-trigger"
data-bb-lightbox-group="gallery"
data-bb-lightbox-src="https://picsum.photos/id/1015/1600/1200"
alt="Dağ manzarası" />
