Size variants
Not: Button’lar senin mevcut .btn token sistemini kullanır.
Events (console)
bb.dialer.increase / increased / decrease / decreased / change / changed
How do I use it?

Sayı seçici

data-bb-dialer kökü; data-bb-dialer-min|max|step|decimals|prefix ile sınırlar verilir. Artı/eksi düğmelerine data-bb-dialer-control eklenir.

HTML 
<div class="input-group bb-dialer w-100"
     data-bb-dialer="true"
     data-bb-dialer-currency="true"
     data-bb-dialer-min="1000"
     data-bb-dialer-max="50000"
     data-bb-dialer-step="1000"
     data-bb-dialer-decimals="0"
     data-bb-dialer-prefix="$">
    <button class="btn bb-dialer-btn" type="button" data-bb-dialer-control="decrease" aria-label="Decrease">
        <span class="material-symbols-outlined">remove</span>
    </button>

    <input type="text"
           class="form-control bb-dialer-input"
           readonly
           value="$10000"
           placeholder="Amount"
           data-bb-dialer-control="input" />

    <button class="btn bb-dialer-btn" type="button" data-bb-dialer-control="increase" aria-label="Increase">
        <span class="material-symbols-outlined">add</span>
    </button>
</div>
