Bu card, sayfa scroll oldukça sağ tarafta sticky kalır. JS yok; saf CSS position: sticky.
Footer note
How do I use it?

Yapışkan kutu

bb-sticky + top ayarı (bb-sticky-top-100). Katman sırası için bb-sticky-z-95 gibi sınıflar; header menülerinin altında kalması için değerler 1030 altında tutulur.

HTML 
<div class="bb-sticky bb-sticky-end bb-sticky-top-100 bb-sticky-w-lg-300 bb-sticky-z-95"
     data-kt-sticky="true"
     data-kt-sticky-name="docs-sticky-summary"
     data-kt-sticky-offset="{default: false, xl: '200px'}"
     data-kt-sticky-width="{lg: '250px', xl: '300px'}"
     data-kt-sticky-left="auto"
     data-kt-sticky-top="100px"
     data-kt-sticky-animation="false"
     data-kt-sticky-zindex="95">
    <div class="bb-card card">
        <div class="bb-card-header">
            <div class="card-title mb-0">Sticky Summary</div>
            <div class="bb-card-actions">
                <button class="btn btn-sm btn-primary">Save</button>
            </div>
        </div>

        <div class="bb-card-body">
            <div class="d-flex align-items-center justify-content-between py-2"
                 style="border-bottom: 1px dashed var(--bb-border-color);">
                <div class="text-muted">Status</div>
                <div class="fw-semibold">Active</div>
            </div>

            <div class="d-flex align-items-center justify-content-between py-2"
                 style="border-bottom: 1px dashed var(--bb-border-color);">
                <div class="text-muted">Top</div>
                <div class="fw-semibold">100px</div>
            </div>

            <!-- ... aynı yapıda diğer öğeler ... -->

            <div class="mt-3 text-muted" style="font-size: 0.875rem;">
                Bu card, sayfa scroll oldukça sağ tarafta sticky kalır.
<!-- ... -->
